# TaskFlow 📋

A Kanban-style project management app with drag-and-drop task cards, priority labels, and deadline tracking.

## Features
- 🎯 4-column Kanban board: To Do, In Progress, Done, Blocked
- 🖱️ Drag & drop tasks between columns
- ⬅️➡️ Arrow-button task movement
- 🔴🟡🟢 Priority labels (High / Medium / Low)
- 📅 Deadline tracking with overdue warnings
- 📊 Progress bar per task
- 🔍 Live search + priority filter
- 💾 Persistent state via localStorage
- ✏️ Full task edit / delete
- 📈 Stats bar (total / done / blocked counts)

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- Drag & Drop HTML5 API
- localStorage for data persistence
- Google Fonts (Plus Jakarta Sans)

## Getting Started
```bash
open index.html
# OR
npx serve .
```
